# Observational dashboard

Type: prototype
Status: open
Blocked by: 02, 07

## Question

What should a rough observational dashboard show, so we can react to it before the spec freezes the UI?

It lists **Runs** and opens one run's **Attempts**, retries, failures, and **Compensation**. It must be able to show every state from [Run lifecycle](02-run-lifecycle.md) using the data from [Run HTTP API](07-run-http-api.md). It does not author workflows.
